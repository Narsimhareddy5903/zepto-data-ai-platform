\# Module 1 — Data Pipeline



This module builds a data pipeline for books from Books to Scrape.



The pipeline will:



1\. Scrape book information using `requests` and BeautifulSoup.

2\. Clean and transform the scraped data.

3\. Store the cleaned data in a normalized SQLite database.

4\. Run SQL queries against the database.

5\. Read SQL results into pandas for analysis.

6\. Reproduce a SQL JOIN using pandas `merge`.
